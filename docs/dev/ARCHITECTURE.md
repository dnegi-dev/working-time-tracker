# Architecture

```
ui (Svelte) ──► application ──► domain
   │                 │             ▲
   └──► i18n         └──► ports ◄──┤
                                   │
adapters (storage, holidays, automation, export) ──► ports, domain
main.ts + wiring/  = composition root (only place that imports adapters)
```

| Layer       | Path                        | Contains                                                             | May import                |
| ----------- | --------------------------- | -------------------------------------------------------------------- | ------------------------- |
| domain      | `src/domain`                | types, time math, breaks, balance, quota, immutable edits            | nothing                   |
| ports       | `src/ports`                 | interfaces: Repository, Clock, HolidayProvider, FileAccess, Platform | domain (types)            |
| application | `src/application`           | `createApp` store, command registry, report, backup, auth            | domain, ports, zod        |
| adapters    | `src/adapters`              | localStorage/file repos, iCal, deep links, SW bridge, formatters     | domain, ports, libraries  |
| ui          | `src/ui`                    | screens, components, `Ui` context, router                            | application, domain, i18n |
| i18n        | `src/i18n`                  | `en` (source of keys), `de`, `t()`                                   | nothing                   |
| composition | `src/main.ts`, `src/wiring` | wiring adapters into ports                                           | everything                |

Enforced by `npm run arch` (dependency-cruiser). Files are capped at 200 lines (ESLint `max-lines`).

## Data flow

- **All state** is one immutable `Dataset` held by `createApp` (`src/application/app.ts`).
- **Mutations:** `app.update(fn)` with a pure function from `domain/edit.ts` / `domain/tracking.ts`, or `app.run(command, params, source)` for the public commands.
- **Commands** (`src/application/commands/registry.ts`) are the single source for deep links, the service-worker HTTP API and `public/api/openapi.json` (generated by `scripts/gen-openapi.ts`).
- **Persistence:** adapters partition the dataset per month/year/single file (`adapters/storage/partition.ts`).

## Recipes

- **New command:** add an entry to `commands` in `registry.ts` → `npm run gen:openapi` → add a unit test in `tests/unit/application.test.ts` → mention it in `docs/user/*/command-api.md`.
- **New setting:** field + default in `domain/types.ts` / `domain/dataset.ts` (migrate fills defaults) → UI in `ui/components/settings/*` → keys in `i18n/en.ts` and `de.ts`.
- **New text:** add the key to `en.ts` first; typecheck then requires it in `de.ts`. `npm run i18n` rejects raw text in templates.
- **Schema change:** bump `SCHEMA_VERSION` and extend `migrate()` in `domain/dataset.ts`.
- **Database backend:** implement `Repository` in `adapters/storage/dbRepo.ts`, wire it in `wiring/storage.ts`. See ADR 0003.
