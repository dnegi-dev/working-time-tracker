# Installieren

**Ziel:** die App mit einem Tipp erreichen.

**iPhone (Web-App):** `https://dnegi-dev.github.io/working-time-tracker/` in Safari öffnen → anmelden (Standard `admin` / `admin`) → Teilen → **Zum Home-Bildschirm**. Funktioniert nach dem ersten Aufruf offline.

**iPhone (native App):** einmalig auf einem Mac bauen, siehe [iOS-Build](../../dev/ios.md). Automationen öffnen sie direkt über `wtt://`-Links.

**Desktop:** URL in Chrome/Edge öffnen → Installieren-Symbol in der Adressleiste. Die installierte App empfängt `web+wtt://`-Links.
