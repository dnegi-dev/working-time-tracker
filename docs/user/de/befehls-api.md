# Befehls-API (Swagger)

1. App öffnen und anmelden (Tab offen lassen).
2. **Einstellungen → Automatisierung → Befehls-API (Swagger)**.
3. Befehl wählen → **Execute**. Der Aufruf läuft im offenen App-Tab.

Jeder Befehl gibt es als `wtt://toggle` (iOS-App), `…/#/do/toggle` (Web) und `GET …/api/v1/toggle` (HTTP im Browser). Ohne offenen App-Tab antwortet die API mit **503**.
