# Speicher, Sicherung & Wiederherstellung

**Speicherort** (Einstellungen → Daten): _Dieses Gerät_ (Standard) oder _Dateien_ – eine pro Monat, pro Jahr oder eine Datei. iOS-App: _Dateien → Auf meinem iPhone → Working Time_. Desktop-Chrome/Edge: Ordner wählen. In Safari nicht verfügbar. Eine Kopie bleibt immer im Gerätespeicher.

Web-App und iOS-App haben getrennte Daten – per Sicherung übertragen.

**Sicherung erstellen** speichert eine vollständige JSON-Datei mit Prüfsumme. **Wiederherstellen…** → Datei → Vorschau → **Ersetzen** oder **Zusammenführen**. Beschädigte Dateien werden abgelehnt.
