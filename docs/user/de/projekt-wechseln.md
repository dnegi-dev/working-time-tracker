# Projekt wechseln

1. Unter **Projekte** Namen eingeben → **Hinzufügen**.
2. Auf **Heute** das Projekt wählen. Während der Erfassung wird die Zeit beim Wechsel aufgeteilt.
3. Automatisch per QR/NFC mit dem Befehl `switch-project`, siehe [NFC & QR](automatisieren-nfc-qr.md).

**Projekte** zeigt die Stunden des Monats; ein Projekt antippen für Summe und Notizen. **Archivieren** blendet erledigte Projekte aus.
