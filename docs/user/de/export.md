# Bericht exportieren

1. **Einstellungen → Daten → Bericht exportieren.**
2. Bereiche wählen: **Stunden, Projekte, Saldo & Quote, Notizen**.
3. Zeitraum und Format wählen: **Markdown, CSV, JSON, Excel** → **Exportieren**.

Eine Tabelle pro Bereich (Excel: ein Blatt pro Bereich). Exporte lassen sich nicht importieren – dafür gibt es Sicherungen.
