# Days off

**Goal:** vacation and sick days should not count as missing hours or office days.

- Today: **Today → Day type** → Vacation / Sick / Holiday.
- Any date, by link: `wtt://mark-day?type=vacation&date=2026-12-24` (`type=none` removes it).

**Result:** the day's target becomes 0 and it no longer counts as a workday for the quota.
