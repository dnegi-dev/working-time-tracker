# Install

**Goal:** have the app one tap away.

## iPhone — web app (PWA)

1. Open `https://dnegi-dev.github.io/working-time-tracker/` in Safari.
2. Log in (default `admin` / `admin`).
3. Share → **Add to Home Screen**.

Works offline after the first visit. For NFC/leaving-work automation, the iOS app is more reliable (see [NFC & QR](automate-nfc-qr.md)).

## iPhone — native app

Build it once on a Mac: see [iOS build](../../dev/ios.md). Automations then open it directly via `wtt://` links.

## Desktop

Open the URL in Chrome or Edge → install icon in the address bar. The installed app can receive `web+wtt://` links.

**Result:** the app starts on **Today**.
