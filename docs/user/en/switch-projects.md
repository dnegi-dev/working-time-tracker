# Switch projects

**Goal:** know which project your hours went to.

1. Create projects under **Projects** → type a name → **Add**.
2. On **Today**, pick the project in **Project**. While tracking, switching splits the time at that moment.
3. Automate it with a QR code or NFC tag per project: see [NFC & QR](automate-nfc-qr.md) (command `switch-project`).

Project hours for the month are listed under **Projects**; tap a project for its total and notes. **Archive** hides finished projects without losing data.
