# Export a report

**Goal:** get your data out for your employer, taxes or your own analysis.

1. **Settings → Data → Export report.**
2. Tick one or more goals: **Hours**, **Projects**, **Balance & quota**, **Notes**.
3. Choose the range (week, month, year, custom) and format: **Markdown, CSV, JSON, Excel**.
4. **Export.** Web: file download. iOS app: _Files → Working Time → WorkingTime/Exports_.

**Result:** one table per goal (Excel: one sheet per goal). Exports cannot be imported — use [backups](storage-and-backup.md) for that.
